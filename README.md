# Conexão Catadores

Site institucional do projeto Conexão Catadores, com foco na realidade dos catadores de materiais recicláveis e na valorização do trabalho desenvolvido no Brasil.

## 🌐 Versão online

A versão online está disponível em:
https://conexao-catadores.netlify.app/

## 📋 Sobre o projeto

O site apresenta informações, dados, histórias e referências sobre os catadores brasileiros, destacando:
- a importância social e ambiental do trabalho;
- as condições de trabalho e a renda;
- o impacto da reciclagem na economia circular;
- ações que a sociedade pode tomar para apoiar e valorizar essa categoria.

## 🧱 Estrutura do projeto

- index.html: estrutura principal do conteúdo em seções.
- css/style.css: estilos, paleta de cores, layout responsivo e componentes visuais.
- js/main.js: interações como menu mobile, animações ao rolar, accordion e modais.
- assets/img: imagens, logos e elementos visuais utilizados no site.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (variáveis, flexbox, grid, responsividade)
- JavaScript (Intersection Observer, manipulação de DOM, menu e animações)
- Google Fonts

## ▶️ Como executar localmente

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no navegador.
3. Acesse o arquivo index.html diretamente ou utilize um servidor simples, como:
   - Python: `python -m http.server 8000`
   - Depois abra `http://localhost:8000`.

## 📱 Responsividade

O layout foi desenvolvido para funcionar de forma fluida em diferentes telas, com adaptações para:
- desktop;
- tablets;
- celulares.

## ✨ Funcionalidades principais

- navegação com menu responsivo;
- scroll reveal com animações ao rolar a página;
- accordion para perguntas frequentes;
- cards e modais com conteúdo expandido;
- apresentação visual com foco em identidade e storytelling.

## 🖼️ Como alterar as mídias do projeto

As imagens e elementos visuais podem ser trocados de forma simples:

1. Substitua os arquivos existentes na pasta assets/img.
2. Atualize os caminhos nas tags `<img>` no arquivo index.html.
3. Para fundos decorativos ou imagens de apoio, ajuste os caminhos em css/style.css.
4. Se quiser mudar o logo, o favicon ou a imagem principal da home, troque os arquivos correspondentes em assets/img.

Exemplos de arquivos comuns para substituir:
- marcaCC-cabecalho.svg
- logo-ufc.png
- catadoresdobrasil1.jpg
- quemsao1.jpg
- arotinadoscatadores1.jpg
- arotinadoscatadores2.jpg
